# microsd (vde)

Lettore di microSD (SPI) come driver ELF: montaggio, stato, comandi sd e formattazione.

- Tipo: driver
- Autore: Domenico Paolella
- Versione: 1.0
- Licenza: CC0-1.0
- SHA-256: `c92cbcb8e66f9a3044ff41374749b142ec6e8901368b6975af0f52c3a69ab745`

Come si installa: scarica `microsd.vde`, apri nella pagina della scheda il pannello Driver e usa Carica. Dalla shell: `vesevos-driver install`.
