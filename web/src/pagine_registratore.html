Registratore

Ogni tanto legge le fonti scelte (periferiche, temperatura del chip, RAM libera) e scrive una riga in un file CSV, sulla memoria interna o sulla microSD. Parte spento. Le righe si scrivono a blocchi per non consumare la memoria.

Azioni

Le azioni non si campionano: si segna l'ora in cui sono state eseguite (uscite, PWM, LED, contatore, programmi, riavvii, sonno, avvio, rete, servizi, microSD). Non si segnano accessi, password o nomi utente. Vanno nel file eventi.csv.
