Punto di accesso (AP)

Il punto di accesso serve quando la scheda non e collegata a nessuna rete: ti colleghi direttamente alla scheda con il Wi-Fi. Se il collegamento alla tua rete fallisce, la scheda torna da sola in questo modo.

LED

  
  
  
  

  
Colori di stato: arancio = avvio, blu = AP, giallo = connessione, verde = client collegato, rosso lampeggiante = errore.


LED aggiuntivo (rosso)

  
  
  
  
  

  
Pin ammessi: 1-18, 21 e 38-47. Se il LED non reagisce prova un altro pin o il livello invertito. Il pin scelto compare nella scheda Pin.





 
Pin e prove

  
Tocca un pin verde per provarlo. Blu = pin in uso, grigio = vietato.

Password sulla seriale

  
Proteggi la seriale (cavo USB) con la password

  

  
Pagina web, shell web e API sono sempre protette dalla password. Se spegni questo interruttore, chi collega il cavo USB ottiene subito la shell. Il tasto BOOT premuto 8 secondi azzera la password e riaccende la protezione.
